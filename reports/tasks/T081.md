# T081 — Redact STALE Fedora telemetry identity in Control Center

## Objectif

Quand la télémétrie Fedora AUTOPILOT est STALE, ne jamais présenter head/branch/taskId historiques comme identité live de l’exécuteur.

## Livrables

- `redactStaleExecutorIdentity` + application dans `readFedoraTelemetrySnapshot`
- ACTIVE AGENT : libellé `EXECUTEUR_INDISPONIBLE` + `INCONNU (STALE)` sans fallback sur `git.head`
- Tests unitaires de rédaction STALE

## Preuves

- quality-gate local QUALITY_GATE_OK (validate + x200:test + telemetry.test.ts)
- MERGED=NO DEPLOYED=NO

## Sécurité

- Aucun secret dans télémétrie
- STALE ne peut plus afficher un SHA historique (ex. `abc1234`) comme HEAD live
