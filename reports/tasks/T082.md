# T082 — Bind Control Center CI SUCCESS to matching commit SHA

## Objectif

Le SUCCESS CI affiché pour le commit courant ne doit jamais provenir d’un run dont le `head_sha` diffère du HEAD/PR affiché.

## Livrables

- `ciLatestHeadSha` + `ciShaMatch` sur `GithubSnapshot`
- `selectWorkflowRunForCommit` / `bindCiToDisplayedCommit`
- `readGithubSnapshot({ expectedSha })` via `git.head`
- Health : MISMATCH ⇒ critère CI failed / conclusion non publicisée comme SUCCESS

## Preuves

- quality-gate local QUALITY_GATE_OK
- MERGED=NO DEPLOYED=NO

## Sécurité

- GitHub indisponible → NOT_CONNECTED (pas de faux SUCCESS)
- Ancien SUCCESS de branche ≠ validation du commit courant
