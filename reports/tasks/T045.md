## Protections

- Enum strict `AUTOPILOT_START|STOP|RESTART|RUN_ONE_CYCLE` uniquement
- `execFile` argv fixes ; jamais `exec` / `shell:true` / commande navigateur
- SUPER_ADMIN only mutations ; ADMIN lecture seule ; same-origin CSRF
- Human Gate / dirty worktree / agentBusy / CONTROL_DISABLED
- STOP/RESTART refusés si `agentRunning=true` (pas de FORCE STOP)
- MERGE / DEPLOY UI = Human approval required
- Audit `.x200/control-actions.jsonl` (gitignored, 0600, redacté)
