# T048 — X200 Boot Orchestrator

## Objectif

Démarrage automatique Fedora → Docker DB → Control Center (127.0.0.1:3001) → Autopilot → watchdog → ouverture navigateur après login graphique.

## Livrables

- Installer idempotent `npm run x200:autostart:{install,status,repair,disable}`
- Unités user systemd Control Center + Autopilot + watchdog timer
- Port 3001 ownership safe (ALREADY_RUNNING / CONFLICT, jamais de kill unknown)
- DB `clevones-x200-db` restart `unless-stopped`
- Linger détecté sans sudo silencieux
- XDG autostart browser once-per-session (`xdg-open` argv fixe)
- Onglet STARTUP + badge BOOT dans `/admin/x200`
- Actions allowlistées + audit
- Docs `docs/X200_BOOT_AUTOSTART.md`

## Preuves locales

- CONTROL_CENTER_SERVICE_INSTALLED=YES / ENABLED=YES
- CONTROL_CENTER_HTTP=OK (307)
- PORT_3001_OWNER=X200 / UNKNOWN_PROCESS_KILLED=NO
- DB_AUTOSTART_POLICY=unless-stopped / DB_RUNNING=YES
- BROWSER_AUTOSTART_INSTALLED=YES
- USER_LINGER=YES
- Unit tests + x200:test + lint + tsc + prisma + build + secrets PASS
