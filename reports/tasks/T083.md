# T083 — Durable task checkpoint for verified resume

## Objectif

Persister un checkpoint vérifié sur les tâches `EN_COURS` pour reprendre après expiration de bail sans rejouer d’effets externes incertains.

## Livrables

- `checkpoint` + `maxAutomaticAttempts` (défaut 2 reprises)
- `setTaskCheckpoint` (holder only)
- Préservation checkpoint sur release / re-claim + nouvel `executionId`
- Refus `MAX_AUTOMATIC_ATTEMPTS` après initial + 2 reprises

## Preuves

- quality-gate local QUALITY_GATE_OK
- MERGED=NO DEPLOYED=NO
